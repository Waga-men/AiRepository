# Playerok Tools — Telegram-бот

Telegram-версия расширения **Playerok Tools** для продавцов `playerok.com`.
Повторяет функционал расширения, но работает в Telegram: дашборд, чаты, лоты,
авто-поднятие, авто-перевыставление, команды, сообщение при возврате, аналитика.

> Самостоятельная реализация. Не является официальным продуктом Playerok.
> Используйте только для собственного аккаунта и с учётом правил Playerok.

## Функции

- **Дашборд** — аккаунт, баланс, счётчик непрочитанных.
- **Чаты** — список диалогов, чтение сообщений, ответ, шаблоны, «прочитать все».
- **Лоты** — список с фильтрами, ручное поднятие/выставление с выбором тарифа, экспорт CSV.
- **Авто**:
  - чат-автоматизация — автоответы по ключевым командам, уведомления в Telegram, авто-прочтение;
  - авто-поднятие активных лотов (бесплатно);
  - авто-перевыставление истёкших лотов (бесплатно или платно, с лимитами «макс. сумма» и «мин. баланс»);
  - сообщение при возврате (откате) сделки.
- **Аналитика** — продажи, оборот, средний чек, проблемные сделки, топ товаров, экспорт CSV.
- **Резервная копия** настроек в JSON.

## Установка

```bash
cd playerok-bot
pip install -r requirements.txt
```

В папке лежит готовый локальный сервер `telegram-bot-api-win64.zip` —
`run.py` сам его распакует (или скачает, если zip отсутствует).

## Запуск (Windows, обход блокировки)

Бот работает через **локальный Bot API сервер** (так `api.telegram.org`,
заблокированный в РФ, не нужен).

1. Получите токен бота у [@BotFather](https://t.me/BotFather).
2. Получите `api_id` и `api_hash` на https://my.telegram.org
   (войдите по номеру → **API development tools** → создайте приложение).
3. Запустите одной командой:

```bash
python run.py
```

или двойным кликом по `start.bat`.

Скрипт сам спросит `BOT_TOKEN`, `API_ID`, `API_HASH` (при первом запуске),
запишет их в `.env`, запустит локальный сервер и бота. Всё, что нужно
заполнить руками — три значения.

> При следующем запуске спрашивать ничего не будет — значения уже в `.env`.

### Как это работает
- `telegram-bot-api.exe` (локальный сервер) запускается на `http://localhost:8081`
  и связывается с Telegram по MTProto (как обычное приложение Telegram — в РФ работает).
- Бот обращается к `localhost:8081`, а не к заблокированному `api.telegram.org`.

### Если есть VPN/прокси
Можно обойтись без локального сервера — в `.env` укажите прокси:
```
PROXY=http://127.0.0.1:7890
```
и запускайте обычным `python bot.py`.

## Доступ и оплата

Бот платный. Права:

- **Владелец** (`OWNER_ID`) — постоянный доступ + админ-панель.
- **Пользователь** — доступ выдаёт владелец (`/grant @user` или `/grant ID`)
  либо покупает сам (`/buy`).

Способы оплаты в `/buy`:

1. **⭐ Звёзды Telegram** — инвойс, доступ активируется автоматически после оплаты.
2. **💳 Перевод на карту** — пользователь отправляет сумму, владельцу приходит
   уведомление-заявка, владелец выдаёт доступ вручную (`/grant`).

Настройка цен и номера карты — в админ-панели (`/admin` → «Цены и реквизиты»).

### Команды владельца

- `/admin` — админ-панель
- `/grant @user|ID` — выдать доступ
- `/revoke @user|ID` — забрать доступ
- `/prices` — цены и реквизиты

## Подключение аккаунта Playerok

Бот работает на сервере, поэтому ему нужна ваша сессия Playerok (cookies).
Получить их можно так:

1. Откройте `playerok.com` в браузере и войдите в аккаунт.
2. Откройте расширение **EditThisCookie**.
3. Нажмите **Export** (иконка со стрелкой) — в буфер скопируется JSON всех cookies.
4. В боте отправьте `/login` и вставьте этот JSON.

Также подходят:

- команда **Copy as cURL** из DevTools (Network → правый клик по запросу `/graphql` → Copy → Copy as cURL);
- строка cookie вида `name=value; name2=value2`;
- одиночное значение сессионного токена.

Бот сохраняет cookies локально и использует их только для запросов к Playerok.

## Важно про DDoS-Guard

Playerok защищён DDoS-Guard, который проверяет IP и TLS-отпечаток. Чтобы бот
работал надёжно:

- запускайте его **с того же региона/сети, где вы обычно сидите в Playerok**
  (например, на своей машине или на VPS в РФ);
- если сессия периодически «отваливается» — просто обновите cookies через `/login`.

## Структура

| Файл | Назначение |
| --- | --- |
| `bot.py` | хендлеры Telegram, меню, FSM-диалоги |
| `client.py` | клиент GraphQL Playerok (порт `page-api.js`) |
| `automation.py` | авто-циклы: чат, поднятие, перевыставление, возвраты |
| `analytics.py` | расчёт аналитики, CSV |
| `storage.py` | хранение настроек/состояния (JSON в `data/`) |
| `fmt.py` | форматирование |
| `config.py` | чтение `.env` |

## Ограничения

- Отдельные функции опираются на внутренний GraphQL Playerok; после обновлений
  сайта может потребоваться правка (особенно хэш `itemPriorityStatuses`).
- Платное перевыставление списывает реальные деньги с баланса — настройте
  «Мин. баланс» и «Макс. сумму», чтобы не слить баланс.
